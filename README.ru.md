# Obsidian Image Optimizer

[English](README.md) | [Русский](README.ru.md)

Делает картинки в заметках [Obsidian](https://obsidian.md) лёгкими и локальными: картинки из интернета скачиваются в хранилище и сжимаются в WebP с качеством, при котором разница не видна глазу (**40** по умолчанию), — обычно **в 5–8 раз меньше** для скриншотов и картинок из интернета. Ссылки в заметках обновляются автоматически.

Это **плагин для Obsidian** (`obsidian-plugin/`), который работает на **Windows, macOS, Linux, Android и iOS** без установки чего-либо в операционную систему: кодировщик WebP (libwebp — библиотека, на которой построен `cwebp`) скомпилирован в WebAssembly и встроен в плагин.

## 📱 Плагин для Obsidian

### Что делает
- **Скачивает картинки из интернета** (`![](https://…)` и `<img src="https://…">`) в выбранную папку и переводит ссылки на локальные файлы. Принимаются только настоящие картинки: HTML-страница «hotlinking denied» никогда не заменит вашу ссылку.
- **Сжимает в WebP** — JPG, PNG и BMP в WebP, **анимированные GIF в анимированный WebP**. Для PNG, BMP и GIF плагин выбирает сжатие по содержимому: мало цветов и мало изменений между кадрами (скриншоты, схемы, записи экрана) — без потерь (lossless), пиксель в пиксель; много цветов или кадры, меняющиеся целиком (фото, рендеры, видео), — с потерями (lossy). Если выбранный режим не дал экономии, пробуется второй; неочевидные картинки сжимаются обоими способами, и остаётся меньший файл. JPG сжимается только с потерями. Сжатая картинка используется, только если она меньше хотя бы на 5% (настраивается), иначе остаётся оригинал.
- **Сжимает картинки, уже лежащие в хранилище**: WebP сохраняется рядом с оригиналом, все ссылки на него во всех заметках переписываются (встраивания, ссылки, свойства; размеры вроде `|200` сохраняются), а оригинал переносится в папку `.trash` хранилища, откуда его можно восстановить. Если оригинал ещё где-то упоминается — в canvas, свойстве, обычном тексте, — он остаётся на месте.
- **Сжимает при вставке и перетаскивании**: вставленный скриншот сразу сохраняется в WebP, картинки из вставленного текста скачиваются.
- **Не подвешивает интерфейс**: сжатие идёт в фоновом потоке, по одной картинке; у долгой обработки есть прогресс и кнопка остановки.

### Установка
Пока плагина нет в каталоге сообщества, установите его через **BRAT**:
1. Установите и включите плагин сообщества **BRAT**.
2. Выполните **BRAT: Add a beta plugin for testing**, введите `ibrusi/obsidian-local-image-small` и выберите последнюю версию.
3. Включите **Image Optimizer** в *Настройки → Сторонние плагины*.

Вручную: скачайте `obsidian-image-optimizer.zip` из [последнего релиза](https://github.com/ibrusi/obsidian-local-image-small/releases), распакуйте в `<хранилище>/.obsidian/plugins/` (папка `.obsidian` скрытая) и включите плагин.

### Использование
Откройте палитру команд (`Ctrl/Cmd+P` на компьютере; на телефоне — свайп вниз по заметке или через меню) и наберите **image**:

| Команда | Что делает |
| :--- | :--- |
| **Сжать картинки в текущей заметке** | Скачивает картинки из интернета и сжимает картинки заметки. |
| **Сжать картинки во всём хранилище** | То же для всех заметок, с прогрессом и кнопкой «Остановить». |
| **Остановить сжатие картинок** | Останавливает текущую обработку. Готовые картинки остаются готовыми. |

Если включено **Сжимать при вставке и перетаскивании** (по умолчанию), вставленные и перетащенные картинки обрабатываются без команд.

### Настройки
| Настройка | По умолчанию | Описание |
| :--- | :--- | :--- |
| Язык | Как в Obsidian | Английский или русский. По умолчанию плагин берёт язык интерфейса Obsidian, а если такого языка нет — английский. |
| Папка для картинок | `Attachments` | Куда сохраняются скачанные и вставленные картинки: `Attachments` — папка рядом с заметкой; `/Attachments` — одна папка в корне хранилища; пусто — папка самой заметки. Сжатые локальные картинки остаются рядом с оригиналами. |
| Качество | `40` | Качество WebP с потерями, 1–100. На сжатие без потерь не влияет. |
| Степень сжатия | `4` | Метод libwebp, 0–6. `6` даёт файлы примерно на 5% меньше, но в разы медленнее — заметно на телефонах. |
| Минимальная экономия, % | `5` | Оставлять оригинал, если WebP меньше на меньший процент. |
| GIF | Сжимать в WebP | Или оставлять GIF как есть. |
| Сжимать картинки, уже лежащие в хранилище | вкл. | Команды сжимают и локальные JPG/PNG/BMP/GIF и переносят оригиналы в `.trash`. |
| Сжимать при вставке и перетаскивании | вкл. | См. выше. |
| Не сохранять одинаковые файлы | вкл. | Если файл с таким же именем в папке назначения (`pic.webp`, `pic-1.webp`, …) содержит точно такие же байты, ссылка ставится на него, а копия не сохраняется. Выкл.: каждая картинка сохраняется новым файлом. |
| Максимальный размер загрузки, МБ | `30` | Более крупные загрузки отклоняются. |
| Максимальный размер картинки, мегапикселей | `50` | Более крупные картинки остаются как есть (для анимации — ширина × высота × кадры), чтобы не исчерпать память телефона. |
| Разрешить адреса локальной сети | выкл. | По умолчанию ссылки на `localhost`, `*.local` и частные, loopback и link-local IP-адреса отклоняются, чтобы заметка из недоверенного источника не могла прощупать вашу сеть. |
| Вести журнал в заметке | выкл. | Дописывает подробности каждого запуска в `image-optimizer-log.md` (на английском, для поиска проблем). |

Настройки плагина хранятся в `.obsidian/plugins/obsidian-image-optimizer/data.json`; если ваша синхронизация не переносит `.obsidian/plugins`, задайте их на каждом устройстве.

### Полезно знать
- EXIF-метаданные (дата, GPS) в сжатых картинках не сохраняются; поворот фотографий с телефона применяется к пикселям.
- Файлы никогда не перезаписываются: новые файлы получают свободное имя (`pic.webp`, `pic-1.webp`, …). Если файл с таким именем уже содержит точно такие же байты (одна и та же картинка в двух заметках), он переиспользуется вместо сохранения копии (настройка *Не сохранять одинаковые файлы*).
- Ссылки внутри блоков кода, инлайн-кода и комментариев не трогаются. Открытые в редакторе заметки сохраняются перед изменением.
- WebP повторно не перекодируется, поэтому повторный запуск не ухудшает качество.

## 🧪 Разработка

### Плагин
```bash
cd obsidian-plugin
npm ci
npm run typecheck
npm test               # юнит-тесты (Node 22.18+)
npm run test:browser   # кодировщики в Chromium и WebKit (нужны браузеры Playwright)
npm run build          # main.js
```
Релиз публикуется CI для каждой новой версии в `manifest.json` (версию в `package.json` держите такой же); версии с суффиксом вроде `2.0.0-beta.3` — pre-release.

CI (`.github/workflows/ci.yml`) запускает те же проверки, включая кодировщики в Chromium и WebKit.
