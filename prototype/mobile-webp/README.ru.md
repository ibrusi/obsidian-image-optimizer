# Прототип WebP (десктоп и мобильные)

Временный прототип: проверяем, можно ли скачивать картинки и сжимать их в WebP
**прямо внутри Obsidian на любой платформе** — Windows, macOS, Linux, Android и
iOS — без установки чего-либо в ОС.

Используется libwebp, скомпилированный в WebAssembly (`@jsquash/webp`) и
встроенный в `main.js`. Это та же библиотека, на которой построен `cwebp`, с
настройками десктопной утилиты (`-q 40 -m 6`), поэтому результат совпадает с
утилитой байт в байт.

> Проверяйте на копии хранилища: прототип создаёт файлы и переписывает ссылки.

## Команды

| Команда | Что делает |
|---|---|
| **WebP Prototype: Benchmark the first image of the current note** | Берёт первую картинку активной заметки (локальную, а если её нет — первую из интернета), сжимает её всеми доступными способами и пишет время и размеры в `webp-prototype-log.md`. Файлы не меняются. |
| **WebP Prototype: Download and convert remote images of the current note** | Скачивает все картинки `![](https://…)` активной заметки. JPG/PNG/BMP сжимаются в WebP; WebP сохраняется, только если он меньше, иначе сохраняется оригинал. Файл кладётся в папку вложений из настроек Obsidian, ссылка переписывается в формате из настроек. GIF и WebP сохраняются как есть. |

## Установка

**Через BRAT** (десктоп, Android, iOS): установите плагин сообщества *BRAT*,
выполните *BRAT: Add a beta plugin for testing*, введите
`ibrusi/obsidian-local-image-small` и выберите версию `0.1.0-prototype.2`.
Затем включите *WebP Prototype* в *Настройки → Сторонние плагины*.

**Вручную**: скачайте `webp-prototype.zip` из релиза
[`0.1.0-prototype.2`](https://github.com/ibrusi/obsidian-local-image-small/releases/tag/0.1.0-prototype.2),
распакуйте в `<хранилище>/.obsidian/plugins/` (папка `.obsidian` скрытая; на
Android включите показ скрытых файлов в файловом менеджере), перезапустите
Obsidian и включите плагин.

## Порядок проверки

1. Создайте заметку с тремя картинками: скриншот (PNG), фото с телефона (JPG,
   от 12 Мп) и небольшая картинка из интернета (`![](https://…)`).
2. Запустите **Benchmark** для каждой (проверяемая картинка должна стоять в
   заметке первой).
3. Создайте заметку с 5–10 картинками из интернета и запустите
   **Download and convert**. Проверьте, что картинки отображаются, ссылки ведут
   на локальные `.webp` и на глаз изображения не изменились.
4. Пришлите `webp-prototype-log.md`.

Проверяем на десктопе и на Android; на iOS — если будет устройство.

## Что уже проверено

- Кодировщик работает в Chromium (движок Obsidian на десктопе и Android);
  прогон в WebKit (движок iOS) входит в CI.
- На тестовых картинках размер результата совпадает с
  `ffmpeg -c:v libwebp -quality 40 -compression_level 6` с точностью до 0,01%,
  то есть визуально результат тот же.

## Известные ограничения

- Сжатие идёт в основном потоке: пока кодируется большое фото, Obsidian не
  отвечает. В настоящем плагине это будет Web Worker.
- Анимированные GIF не конвертируются (через canvas доступен только один кадр).
- Только картинки из интернета в активной заметке; без локальных картинок и без
  настроек.

## Разработка

```sh
npm ci
npm run typecheck
npm test               # юнит-тесты (Node 22.18+)
npm run test:browser   # кодировщик в Chromium и WebKit (нужны браузеры Playwright)
npm run build          # main.js
```

Релиз публикуется автоматически при пуше в ветку `feat/mobile-webp-prototype`,
если релиза с версией из `manifest.json` ещё нет: чтобы выпустить новый,
поднимите версию в `manifest.json` и `package.json`.
